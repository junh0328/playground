# 발행 전 체크리스트

## 콘텐츠
- [ ] 제목이 내용을 정확히 반영하는가?
- [ ] 서론에서 글의 목적과 대상이 명확한가?
- [ ] 본론의 논리적 흐름이 자연스러운가?
- [ ] 결론에서 핵심 내용을 정리했는가?
- [ ] 독자에게 다음 행동을 제안했는가? (CTA)

## 문체
- [ ] 종결어미가 일관적인가? (~합니다)
- [ ] 한 문장이 40자를 넘지 않는가?
- [ ] 이중 피동 표현이 없는가?
- [ ] 용어 표기가 일관적인가?

## 코드
- [ ] 모든 코드 블록에 언어가 명시되었는가?
- [ ] 코드가 실제로 실행 가능한가?
- [ ] 코드에 적절한 주석이 있는가?
- [ ] 실행 결과가 필요한 곳에 포함되었는가?

## 이미지
- [ ] 이미지가 선명한가?
- [ ] alt 텍스트가 설정되었는가?
- [ ] 이미지 크기가 적절한가?
- [ ] 저작권 문제가 없는가?

## 링크
- [ ] 모든 링크가 동작하는가?
- [ ] 외부 링크는 새 탭에서 열리도록 설정했는가?
- [ ] 참고 자료 링크가 포함되었는가?

## SEO
- [ ] 메타 설명이 150자 이내인가?
- [ ] 핵심 키워드가 제목에 포함되었는가?
- [ ] 태그를 5-10개 설정했는가?
- [ ] 카테고리를 지정했는가?

## 반응형
- [ ] 모바일에서 가독성이 좋은가?
- [ ] 코드 블록이 가로 스크롤 없이 보이는가?
- [ ] 이미지가 화면에 맞게 조정되는가?

## 최종 확인
- [ ] 맞춤법 검사를 실행했는가?
- [ ] 미리보기로 전체 확인했는가?
- [ ] 발행 일시를 확인했는가?
